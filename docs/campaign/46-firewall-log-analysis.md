# תסריט חדר 46: Firewall Log Analysis

**שם המבצע:** Operation Deny All
**רמה:** בינוני
**העולם:** Calder Steelworks (מפעל פלדה בדוי): שני כבשני היתוך, מערגלה, וצי חומות אש של FortiGate, ‏Palo Alto ו-Check Point שקנו שלושה מנהלים שונים.
**המנטור:** Viktor Halloran, ראש אבטחת רשת.

## סיפור הרקע
כל חבילה שעוברת בין אזורים משאירה שורה בלוג. בחודש שעבר המחשב הנייד של קבלן "התקשר הביתה" תשעה ימים, והשורות היו שם כל הזמן. Viktor רוצה אנליסטים שקוראים את שלושת היצרנים, רואים beacon בעמודה של חותמות זמן, ויודעים איזה חוק באמת נתן לתעבורה לעבור.

## המכניקה הייחודית של החדר
**סימולטור של rulebase שבו "ההתאמה הראשונה מנצחת":** ארבע זרימות אמיתיות עוברות דרך ארבעה חוקים מלמעלה למטה, והלומד רואה איזה חוק הכריע. אחת מהן מגלה חוק ישן ונשכח, בלי בעלים, שמאפשר למדפסת לצאת לאינטרנט.

## העולם התלת-ממדי: Deny All
- שלושה מכשירי חומת אש (FORTIGATE, ‏PAN-OS, ‏CHECK POINT) על שני קירות אזור (OT · MILL, ‏CORE, ‏INTERNET).
- חוגת beacon מתקתקת ("every 7 min · 612 B").
- ערימת לוחות חוקים שחבילה נופלת דרכם.
- שער deny אדום.
