**שם המבצע:** Operation Packet Trail
**רמה:** מתחילים (חדר שני בסדר הפתיחה)
**העולם:** Harbor Freight Logistics (חברה בדויה), אולם שרתים B, משמרת לילה.
**המנטור:** Ravi Menon, Network Security Lead.

## סיפור הרקע
02:47. תחנת עבודה בחברה פתחה חיבור לצד השני של העולם, והתראה של חומת האש בדרך אליך. Ravi לא נותן לך לגעת בה לפני שתראה בעיניים את מה שחומת האש רואה: כתובות, פורטים, שכבות והמסלול. המשימה היא ללוות פקטה אחת מהלפטופ ועד האינטרנט, ובסוף לקרוא את הלוג של 02:47 כמו אנליסט.

## העולם התלת-ממדי: The Data Path
אולם שרתים עם שורות של ארונות תקשורת ונורות מהבהבות. במרכז יש תוואי כבל אחד: לפטופ ← מתג ← נתב ← חומת אש עם NAT ← כדור אינטרנט ← שרת. מאחוריהם עומד מגדל OSI הולוגרפי של 7 שכבות.
- הלפטופ תמיד דולק. כל תחנה שמסיימים מעלה את ההתקן הבא, והכבל נדלק עד אליו.
- פקטות נוסעות לאורך החלק הדולק. כל פקטה היא קוביית מידע לבנה עטופה בשלוש קליפות: TCP, IP ו-Ethernet.
- מגדל ה-OSI מתמלא מלמטה למעלה ככל שמתקדמים.
- על כל התקן מוצג שם התחנה שמעלה אותו.
