# תסריט חדר 45: VPN Monitoring

**שם המבצע:** Operation Long Distance
**רמה:** בינוני
**העולם:** Northsea Wind (חברת אנרגיית רוח בדויה): ארבע חוות רוח בים, ‏120 טורבינות, ומהנדסים שעובדים מסירות, ממלונות ומהבית, כולם דרך VPN אחד.
**המנטורית:** Eilidh MacLeod, ראש אבטחת גישה מרחוק.

## סיפור הרקע
ה-VPN הוא הדלת הקדמית לרשת הבקרה של הטורבינות. אם מישהו אחר עובר בה עם הסיסמה של מהנדס, הוא יכול לעצור את הלהבים. Eilidh קוראת את לוגי ה-gateway כל בוקר, כמו שמנהל נמל קורא את לוח ההגעות.

## המכניקה הייחודית של החדר
**מסדר זיהוי של דפוסי תקיפה:** ‏The Traveller, ‏The Hammer, ‏The Sprayer, ‏The Stuffer ו-The Squatter. בכל סיבוב מופיע פרץ אירועים מה-gateway, והלומד בוחר מי מהם עשה את זה.

## העולם התלת-ממדי: Long Distance
- gateway במרכז (שני ארונות שרתים ומגן).
- מחשבים ניידים רחוקים (אברדין, אוסלו, ספינה, לית') שמחוברים במנהרות זוהרות.
- מסדר של חמש צלליות תוקפים.
- שביל פנימי אל ה-SCADA historian.
- מגן הכרעה.
