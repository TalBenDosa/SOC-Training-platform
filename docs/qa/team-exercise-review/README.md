## P1/P2: נוף איומים, מה חסר בארסנל
לפי DBIR 2026, ‏M-Trends 2026, ‏CrowdStrike 2026, ‏Sophos ו-Microsoft; הנתונים אומתו מול המקורות.
1. **ניצול edge devices, הווקטור מספר 1** ‏(31%–32%): יש storyline אחד בלבד (`edge-vpn-cve-exploit`, נבנה מחדש על CVE-2022-40684). כדאי להוסיף לפחות שניים: Ivanti/Citrix/PAN-OS ‏GlobalProtect.
2. **Ransomware עדכני בסגנון Akira/Qilin:** כניסה ל-VPN עם חשבון תקף, Impacket, מחיקת גיבויים, ESXi. היום המודל הוא LockBit דרך פישינג.
3. **הנדסה חברתית מחוץ למייל:** Teams vishing עם Quick Assist ו-RMM ‏(Storm-1811), ‏email bombing, ‏device-code phishing ‏(Storm-2372), ‏QR phishing.
4. **צד שלישי ו-SaaS:** גניבת OAuth tokens בין SaaS (בסגנון Salesloft Drift / UNC6395). הספק מעורב ב-48% מהפריצות.
5. **הרס דרך כלי ניהול:** wiper דרך Intune (Handala/Stryker), ‏EDR killing עם driver פגיע ‏(BYOVD).
6. **ייצוג AI גבוה מדי:** 14 storylines. כדאי לצמצם ל-6–8.
7. **חבילות שכבר קיימות ב-`/scenarios` וכדאי להעביר לפיד:** `emailBombHelpdesk`, ‏`vishingRmm`, ‏`lateralMovementPth`, ‏`destructiveWiper`, ‏`goldenSaml`, ‏`azureManagedIdentityAbuse`.
